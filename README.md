## View

뷰 관련 라이브러리

- **Parchment** – Custom TabBar `ViewController`  
  - `https://github.com/rechsteiner/Parchment`
- **TransitionButton** – 전환 애니메이션이 들어간 버튼  
  - `https://github.com/AladinWay/TransitionButton`
- **Malert** – 커스터마이징 가능한 Alert 라이브러리  
  - `https://github.com/vitormesquita/Malert`
- **PinLayout** – Auto Layout 없이 빠르게 레이아웃 구성  
  - `https://github.com/layoutBox/PinLayout`
- **FlexLayout** – CSS FlexBox 스타일 레이아웃  
  - `https://github.com/layoutBox/FlexLayout`
- **SkeletonView** – 스켈레톤 로딩 뷰 라이브러리  
  - `https://github.com/Juanpe/SkeletonView`
- **Carte** – 오픈소스 라이선스 화면 자동 생성 툴  
  - `https://github.com/devxoul/Carte`
- **Shimmer** – 페이스북 스타일 로딩 Shimmer 효과  
  - `https://github.com/facebookarchive/Shimmer`
